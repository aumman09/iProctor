# ผังที่นั่งสอบรายห้อง

หนึ่งห้อง = หนึ่งไฟล์ `<ROOM_ID>.json` (เช่น `C3-107.json`) ระบบอ่านผ่าน `getRoomLayout()` ใน `src/lib/server/data-source.ts`
(ภายหลังเปลี่ยนไปดึงจาก MFU API/DB ได้โดยแก้ฟังก์ชันนั้นที่เดียว)

โครงสร้าง (ตรงกับ `RoomLayoutResponse` ใน `src/lib/types.ts`):
- `groups[]`: `key` (ตัวอักษรนำเลขที่นั่ง เช่น A → A1, A2, ...), `colorTheme` (pink|white|blue|green|yellow ให้ตรงป้ายกระดาษ), `courseName`, `studentIdRange`
- `rows[]`: เรียงจากหน้าห้อง (ไวท์บอร์ด) ไปหลังห้อง — `label` (เช่น "Row 1"), `blocks` = กลุ่มโต๊ะจากซ้ายไปขวา
  แต่ละกลุ่มเป็น array ของเลขที่นั่งตามตำแหน่งเก้าอี้ ใช้ `null` แทนเก้าอี้ว่างที่เว้นไว้ เช่น `["A1", null, null, "A2"]`
  เลขที่นั่งเขียนตรง ๆ ตามผังกระดาษของสำนักทะเบียน จึงรองรับเลขที่วิ่งสลับทิศแต่ละแถวได้ (ดู `C3-101.json`)
- `disabledSeats?`: ที่นั่งที่งดใช้ (แสดงขีดฆ่า)
- `projectorPosition`, `doorPositions` (FRONT_/BACK_ + LEFT/RIGHT — หน้า = ฝั่งไวท์บอร์ด)

ห้องที่มี: `C3-101` (ตามผังจริงของสำนักทะเบียน; ชื่อวิชา/ช่วงรหัสยังเป็น mock), `C3-107` (mock)
