# ผังที่นั่งสอบรายห้อง

หนึ่งห้อง = หนึ่งไฟล์ `<ROOM_ID>.json` (เช่น `C5-302.json`) ระบบอ่านผ่าน `getRoomLayout()` ใน `src/lib/server/data-source.ts`
(ภายหลังย้ายไปเก็บในฐานข้อมูลได้โดยแก้ฟังก์ชันนั้นที่เดียว)

## สร้างจาก PDF ของสำนักทะเบียน (วิธีหลัก)

ต้นฉบับ: https://reg.mfu.ac.th/th/announcement/examination-seating — PDF อาคารละไฟล์ หน้าละห้อง (เป็น vector อ่านข้อความได้)

```bash
pip install pymupdf
python scripts/seating/import_pdf.py C5.pdf --dry-run   # ดูรายงานก่อน
python scripts/seating/import_pdf.py C5.pdf C3.pdf      # เขียนไฟล์ลงโฟลเดอร์นี้ (ทับไฟล์ห้องเดิม)
```

ตัวแปลงอ่านชื่อห้อง, เลขที่นั่ง + พิกัด, สีชมพู/ดำ (= ป้ายชมพู/ขาว), ฝั่งไวท์บอร์ด, ผนังและประตู
รวมถึงตำแหน่งโต๊ะและเก้าอี้ (เก้าอี้ที่มีไอคอนคน = ที่นั่งสอบ) แล้วหมุนผังให้ไวท์บอร์ดอยู่ด้านบนเสมอ — ดูหัวข้อ "ต้องตรวจ" ท้ายรายงาน (เลขซ้ำ/เลขขาด/ไม่พบประตู ฯลฯ)
ไม่ต้องเก็บ PDF ไว้ใน repo (ภายหลังเก็บต้นฉบับใน MinIO)

## โครงสร้างไฟล์ (ตรงกับ `RoomLayoutResponse` ใน `src/lib/types.ts`)

พิกัดทั้งหมดเป็นหน่วย pt ของ PDF หลังหมุนให้หน้าห้องอยู่ด้านบน วัดจากมุมซ้ายบน "ด้านในผนัง" — หน้าจอวาดตามสัดส่วนจริง

- `size`: `{ w, h }` ขนาดด้านในห้อง · `labelSize`: ขนาดตัวเลขที่นั่งในต้นฉบับ
- `whiteboard?`: `{ x, y, w, h }`
- `seats[]`: `{ id, x, y, group }` — x, y = จุดกึ่งกลางตัวเลข; `group` = ตัวอักษรนำเลข (`"A"`, `"B"` หรือ `""`)
- `desks[]`: `{ x, y, w, h }` โต๊ะ (ห้องเก้าอี้เลคเชอร์ไม่มีโต๊ะ)
- `chairs[]`: `{ x, y, w, h, seat? }` — มี `seat` = เก้าอี้ที่ใช้สอบ (ระบายสีตามกลุ่ม), ไม่มี = เก้าอี้ว่างที่เว้นไว้
- `groups[]`: `{ key, colorTheme, courseName?, studentIdRange? }` — สี pink|white|blue|green|yellow;
  ชื่อวิชา/ช่วงรหัสเป็นข้อมูลรายรอบสอบ (จะมาจาก Blendata) ไฟล์ที่แปลงจาก PDF จึงยังไม่มี
- `doors[]`: `{ wall: TOP|BOTTOM|LEFT|RIGHT, at: 0..1 }` ตำแหน่งตามแนวผนัง
- `rowLabels?`: `[{ label, x, y }]` เช่น "Row 1" (อยู่นอกผนังได้)
- `disabledSeats?`: ที่นั่งที่งดใช้ · `source?`: `{ file, page, front }` ที่มาของผัง
