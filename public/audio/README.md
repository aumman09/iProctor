# ไฟล์เสียงประกาศ

วางไฟล์เสียงไว้ในโฟลเดอร์นี้ โดยใช้ชื่อไฟล์ตามตาราง (ตั้งค่าได้ที่ `src/lib/config.ts` → `AUDIO_CUES`)
ถ้ายังไม่มีไฟล์ ระบบจะเล่นเสียง chime สังเคราะห์แทนโดยอัตโนมัติ

| ไฟล์ | เล่นเมื่อ |
| :--- | :--- |
| `01_welcome_entry.mp3` | T-15 นาที เปิดห้องสอบ (08:45 / 13:15) |
| `02_exam_rules.mp3` | T-0 เริ่มสอบ — อ่านระเบียบการสอบ (09:00 / 13:30) |
| `chime_45min_leave.mp3` | T+45 นาที อนุญาตให้ออกจากห้องสอบ |
| `chime_10min_warning.mp3` | เหลือ 10 นาทีก่อนหมดเวลา (แยกตามรายวิชา) |
| `chime_timeout.mp3` | หมดเวลาสอบ (แยกตามรายวิชา) |
