# ไฟล์เสียงประกาศ

วางไฟล์เสียงไว้ในโฟลเดอร์นี้ โดยใช้ชื่อไฟล์ตามตาราง (ตั้งค่าได้ที่ `src/lib/config.ts` → `AUDIO_CUES`)
ถ้ายังไม่มีไฟล์ ระบบจะเล่นเสียง chime สังเคราะห์แทนโดยอัตโนมัติ

| ไฟล์ | เล่นเมื่อ |
| :--- | :--- |
| `01_welcome_entry.mp3` | T-15 นาที เปิดห้องสอบ (08:45 / 13:15) |
| `02_exam_rules.mp3` | T-0 เริ่มสอบ — อ่านระเบียบการสอบ (09:00 / 13:30) |
| `chime_45min_leave.mp3` | T+45 นาที อนุญาตให้ออกจากห้องสอบ |
| `chime_10min_warning.mp3` | เหลือ 10 นาทีก่อนหมดเวลา (แยกตามรายวิชา) |
| `chime_timeout.mp3` | หมดเวลาสอบ (แยกตามรายวิชา) |

ไฟล์ในโฟลเดอร์นี้อยู่บนเซิร์ฟเวอร์ — เครื่องฉายทุกห้องโหลดจากเซิร์ฟเวอร์เอง (preload ตอนกด "เริ่มระบบ") ไม่ต้องก๊อปไปทุกเครื่อง
ยกเว้นเสียงคำชี้แจงที่เลือกผ่านปุ่ม "เลือกเสียงคำชี้แจง" บนจอ ซึ่งเก็บเฉพาะเครื่องนั้น

`chime_45min_leave.mp3` และ `chime_10min_warning.mp3` ไม่ต้องวางก็ได้ — ค่าเริ่มต้นคือกระดิ่งครั้งเดียว (สังเคราะห์ในระบบ)
รองรับ .mp3 / .m4a / .mp4 / .wav — ระบบลองตามลำดับนี้ (ชื่อไฟล์ต้องตรงตามตาราง ต่างกันแค่นามสกุลได้)
